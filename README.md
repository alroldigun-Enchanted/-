# screen-time-voice
Голосовая система для экранного времени.   3 этапа: предупреждение + вызов родителей + полная блокировка.   Снять может только взрослый.   Голос: любой любимый герой фильма, мультфильма, аниме или блогера.   Ребёнок сам переучится, а не как в школе.   Защищает зрение и не требует установки приложений.
